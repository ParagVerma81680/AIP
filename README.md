# AIP - Intelligent Quick Commerce & Physical Store AI

AIP (SwiftMart) is a full-stack quick commerce grocery platform with in-store 2D interactive route navigation and an intelligent AI shopping assistant powered by Groq.

## Backend Features
- FastAPI async REST API with 42 endpoints
- Groq AI integration (`openai/gpt-oss-120b`)
- Long-term memory & conversational RAG engine
- In-store 2D route optimization (A* + TSP 2-opt)
